# Architecture Decision Records

Create an ADR for a durable, consequential, difficult-to-reverse decision such as a public contract, persisted data boundary, security control, cross-module architecture, infrastructure choice, or deliberate exception to an invariant.

Use [`_template.md`](_template.md). Do not rewrite accepted history to reflect a later decision; add a new ADR, link the relationship, and mark the earlier record superseded when appropriate. Update this catalog in the same reviewed change.

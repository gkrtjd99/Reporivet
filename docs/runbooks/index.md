# Runbooks

[`../OPERATIONS.md`](../OPERATIONS.md) is the sole current authority for running, releasing, observing, backup, rollback, recovery, and incidents. Create a separate runbook only when a confirmed procedure must be repeated and is too detailed for that authority.

Use [`_template.md`](_template.md), test every executable step with project-owned tools, assign an owner, and update this catalog in the same reviewed change. Remove an obsolete runbook only after repairing current links and migrating any still-applicable procedure.

# Module Contracts

Create a `MOD-*.md` contract only for a durable multi-file boundary supported by an existing source path or a confirmed planned path. A contract records ownership, responsibility, applicable paths, public entry points, dependency rules, organization, and verification commands. Use `unknown` when evidence is unavailable rather than guessing.

Copy `_template.md` manually, choose a stable `MOD-*` ID, and review links and commands against current source. Module contracts are source-repository notes; initialized targets do not receive this directory or a generated code map.

The former copied-runtime contract is retained as superseded history in [`MOD-HARNESS-RUNTIME.md`](MOD-HARNESS-RUNTIME.md). Current entrypoint ownership is defined by [`ARCHITECTURE.md`](../../ARCHITECTURE.md) and [`SPEC-REPORIVET-003-agent-entrypoints.md`](../product-specs/SPEC-REPORIVET-003-agent-entrypoints.md).

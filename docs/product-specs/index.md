# Product Specifications

Use this directory for long-lived, detailed product behavior shared across multiple changes. Keep product-wide goals and constraints in [`../PRODUCT.md`](../PRODUCT.md).

Create a specification from [`_template.md`](_template.md), assign a stable `SPEC-<AREA>-<NUMBER>` ID, add applicable code and test patterns, then run `./dev/docs-index`.

Do not create a specification for task-specific reasoning that belongs in an active ExecPlan.

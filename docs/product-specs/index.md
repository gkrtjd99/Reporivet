# Product Specifications

Use this directory for long-lived, detailed product behavior shared across multiple changes. Keep current product-wide goals and constraints in [`../PRODUCT.md`](../PRODUCT.md), and keep task-specific reasoning in the matching active Plan.

Create a specification from [`_template.md`](_template.md), assign a stable `SPEC-<AREA>-<NUMBER>` ID, and cite applicable code, tests, decisions, and sources. Update this catalog in the same reviewed change. Superseded records remain historical and must not be treated as current authority.
